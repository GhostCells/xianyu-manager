# 闲鱼本地管理系统

Windows 本地运行的商品管理工具。当前版本以工作区根目录的 `商品库/` 为唯一商品来源，管理数据单独保存在本目录，不会写入客户交付包。可保存多个账号档案，但同时只操作一个当前账号。

## 当前能力

- 扫描 `商品库/NN-商品名/` 并读取标题、ZIP 与五图；
- 复用工作区标准校验器，展示商品是否通过自动质检；
- 记录百度网盘分享链接、提取码和人工验证状态；
- 将商品按账号分配，账号之间隔离建议价格、确认价格、闲鱼商品链接和上架状态；
- 把旧账号已发布商品标记为历史品，阻止误加入新账号，同时保留选品排重依据；
- ZIP 内容变化后保留原链接，但自动标记为“需要重新验证”；
- 使用 SQLite 保存卖家侧数据。
- 使用专用 Edge 配置目录完成闲鱼 App 扫码绑定；数据库不保存 Cookie 值；
- 展示未绑定、待扫码、待确认、已绑定、失效和错误状态，账号切换时保持隔离。
- 通过闲鱼实时消息连接同时监听付款系统事件与普通售前文本，两类消息走独立安全规则；
- 可选自动免拼：只响应“我已小刀，待刀成”平台系统卡片；免拼后等待“我已成功小刀，待发货”再发送交付内容；
- 按闲鱼商品 ID 唯一匹配商品和已验证网盘链接，缺少任一字段即停止发送；
- 对已经在售但没有本地商品目录的历史商品，可按闲鱼商品 ID 单独配置已验证网盘链接；该配置不会占用商品库编号或误配到其他商品；
- 订单号级幂等：链接已发送、确认超时或需人工核对的订单不会重复发送；
- 链接发送成功后可自动确认平台发货，确认失败只补确认、不重发链接；
- 可选硅基流动 DeepSeek AI 自动回复，默认模型为 `deepseek-ai/DeepSeek-V4-Flash`；按闲鱼商品 ID 读取对应商品的《发布文案》作为本地知识库，支持测试生成、随机延迟、消息幂等、人工接管和本地记录；
- 自动回复/发货受每小时、近 24 小时和最小发送间隔限制；发送异常会持久化熔断，重启不能绕过冷却；
- Windows 登录后自动恢复监听，并记录启动健康报告；登录失效、平台风控和恢复成功可显示 Windows 通知；
- 管理页面展示监听状态、最近发货记录与自动回复记录，订单号和会话号只显示末 6 位。

自动上架仍按“系统建议、用户确认、一键提交”的边界继续完善。

## 绑定真实闲鱼账号

1. 打开管理页面，确认右上角选择的是“新账号（当前）”；
2. 点击“扫码绑定真实账号”，系统会打开一个独立 Edge 窗口；
3. 只使用闲鱼 App 扫码登录，不在管理系统中输入密码；
4. 页面显示“已检测到登录”后，在 Edge 里核对账号，再点击“确认绑定这个账号”；
5. Edge 会话保存在 `data/browser-profiles/msedge/account-N/`，该目录已被 Git 忽略。Cookie 值不会写入 SQLite、日志或接口响应。

如果已经绑定，点击“检查或更新登录”会用同一个独立配置目录重新打开闲鱼。上架和订单模块接入后，会在关键操作前再次检查会话是否有效。

## 启动

首次安装可以双击 `安装运行环境.cmd`；以后双击 `启动闲鱼管理系统.cmd` 即可。

也可以在 PowerShell 中运行：

```powershell
cd D:\Projects\副业\闲鱼\xianyu-manager
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

随后打开 <http://127.0.0.1:8765>。

## 自动发货

1. 商品必须已经通过质检、验证百度网盘链接并记录唯一闲鱼商品链接；
2. 点击“连接自检”，按需在专用 Edge 中完成闲鱼扫码或滑块验证；
3. 自检通过后勾选“链接发送成功后确认平台发货”，再点击“开启自动发货”；
4. 如商品开启双人小刀，可勾选“双人小刀待刀成时自动免拼”；
5. 只有收到明确的“买家已付款/等待卖家发货”或受信任的小刀系统卡片才会处理；
6. 无法提取订单号、商品 ID、买家 ID 或会话 ID时停止发送并记录错误；
7. 发货消息确认不明确时转人工核对，系统不会自动重发。

自动发货需要 Windows 已登录、电脑不休眠、网络正常且闲鱼会话有效。当前版本只处理启动后收到的近期实时事件，不会扫描很久以前的历史订单。

## 硅基流动 DeepSeek 自动回复

1. 在管理页的“AI 售前客服”中填写硅基流动 API Key；Key 使用 Windows DPAPI 加密，不以明文写入数据库；
2. 默认选择 `deepseek-ai/DeepSeek-V4-Flash`，点击“测试生成”确认余额与网络正常；
3. 勾选“启用自动回复”并保存。账号已绑定时，系统会自动启动或复用实时消息连接；
4. 只有唯一匹配到当前账号已上架商品的买家普通文本会进入模型；系统会同步读取该商品的 `发布文案.txt`，脱敏后作为商品知识库；付款卡片、拼单卡片和其他系统消息不会进入自动回复；
5. 退款、投诉、侵权、账号密码、验证码、站外联系方式等内容直接转人工；模型输出如包含链接、提取码或联系方式也不会发送；
6. 卖家在会话中人工发言后，该会话默认接管 12 小时，可在管理页提前恢复自动回复；
7. 买家文本与脱敏后的对应商品资料会经硅基流动发送给 DeepSeek；模型必须给出可在商品资料中核验的依据，否则系统转人工。
8. 回复按闲鱼聊天场景去除“您好、这边、简单来说、欢迎咨询”等模板话术；发送前只清理开头和结尾套话，不改型号、数字、价格或交付边界。

自动回复使用硅基流动 OpenAI 兼容接口 `https://api.siliconflow.cn/v1`。API 调用按硅基流动账户计费；系统不会把百度网盘地址、提取码、Cookie、联系方式或密钥放进模型提示词。商品资料没有明确写到的细节会转人工，不允许模型按常识补全。

## 无人值守安全保护

- 默认最多自动回复 20 条/小时、100 条/近 24 小时，自动发货 15 单/小时，任意两次自动发送至少间隔 5 秒；
- 平台返回风控、验证或拒绝发送信号时，默认暂停 30 分钟，期间不继续认证或发送；
- 管理页“无人值守保护”可调整上限、查看使用量、启动检查和熔断原因；请只在确认账号可正常操作后手动解除熔断；
- 登录会话会复用本机专用浏览器目录。正常情况下无需每日确认；但闲鱼主动让会话失效或要求滑块/扫码时，系统只提醒，不会自动绕过验证。

## Windows 登录后自动启动

本机使用计划任务 `XianyuManager` 在当前用户登录 Windows 后启动。也可双击：

- `配置开机自动启动.cmd`：安装或更新启动任务；
- `取消开机自动启动.cmd`：移除启动任务。

启动脚本会先检查 `127.0.0.1:8765`，已经运行时直接退出，防止重复实例。

“同步本地与闲鱼”会先扫描本地商品库，再复用正在监听的登录会话调用闲鱼 PC 个人主页使用的只读商品列表接口，读取最新在售商品；不会打开自动化个人主页或加入浏览器伪装参数。已有商品优先按闲鱼商品 ID 匹配；新商品只在标题相似度足够高且候选唯一时自动绑定，否则保留为待映射，避免错发货。远端结果可能因审核状态暂时缺少商品，因此系统不会仅凭一次缺失暂停已经明确配置为已上架的商品。

## 跨平台运行配置

Windows 未设置下列变量时继续使用原有目录和 Chrome/Edge 自动发现逻辑。Ubuntu
生产部署应显式配置路径，并通过权限受限的 EnvironmentFile 提供密钥：

- `XIANYU_MANAGER_DATA_DIR`：SQLite、浏览器 Profile 和运行状态目录；
- `XIANYU_BROWSER_EXECUTABLE`：Chrome/Chromium 可执行文件的绝对路径；
- `XIANYU_BROWSER_HEADLESS`：浏览器显示模式，默认 `false`；无桌面服务器需要 Xvfb；
- `XIANYU_PRODUCT_LIBRARY_DIR`：商品库绝对路径；
- `XIANYU_PRODUCT_VALIDATOR_PATH`：私有商品校验器绝对路径；
- `SILICONFLOW_API_KEY`：Linux 自动回复密钥；只从进程环境读取，不写入数据库。

浏览器 Profile 由主服务持有跨进程文件锁。独立发布和检查脚本检测到同一
Profile 已被占用时会直接停止，不能与主服务并发运行。Windows 仍可使用原有
DPAPI 密钥文件作为 `SILICONFLOW_API_KEY` 未设置时的回退。

## 自动爆品候选数据出口

选品链路会按 `item_id` 保存搜索命中、详情快照和跨批次趋势。具有至少两次可比较成功快照的商品会生成可解释评估；达到 MVP 阈值后进入独立的 `hot_candidate` 候选阶段，不会自动改变人工审核结论，也不会自动进入商品生产。

Operation 可通过本机只读接口 `GET /api/operation/selection-candidates?limit=50` 获取当前候选。响应版本为 `selection-candidates-v1`，包含商品基本信息、来源关键词、最新互动值、快照差分、单位小时增速、评分拆分、候选原因、自动候选阶段和人工审核状态。缺失的发布时间、商品年龄或互动字段保持 `null`，不会补成 `0`。
