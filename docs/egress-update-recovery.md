# 更新器失败诊断与有界恢复

## 后续抗抖动补丁（取代下面的每次临时失败即撤租策略）

- 前两次明确临时curl错误可进入degraded，但先重查本地路由、规则、UID与授权，且原可信状态仍有效。
- 原20秒状态截止、原30秒内核租约均不延长、不续租；2秒后重试。第3次失败或原截止到期即blocked。
- 硬失败、未知异常、权限或状态损坏无宽限；仍立即阻断。
- 应用blocked后，只在新的成功观测至少2次且稳定10秒后恢复已授权账号2的resident reply-only；恢复尝试间隔至少60秒。
- 恢复不改变数据库回复开关，不启用发货，不恢复订单，不设置cutoff；同一主服务/owner串行恢复。
- noVNC与恢复无关。平台验证失败不会触发反复自动扫码或自动确认。
